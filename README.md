# Программ Бот — Конвертер кода в Telegram

Бот для автоматической конвертации кода из одного языка программирования в другой через Telegram. Использует локальный Ollama с моделью `qwen2.5-coder` для обработки кода, а для управления зависимостями — сверхбыстрый пакетный менеджер `uv`.

## Возможности

- Поддержка 9 языков программирования: Python, JavaScript, Java, C++, Ruby, Kotlin, Swift, Go, C#
- Принимает код в виде **текста** или **файлов** (_.py, _.js, _.java, _.cpp, _.rb, _.kt, _.swift, _.go, _.cs, _.txt)
- Асинхронная обработка запросов
- После конвертации предлагает новый цикл без перезапуска бота
- Интерактивное меню с кнопками выбора языков

## Требования

- Python 3.9+ (контролируется через `uv`)
- Пакетный менеджер `uv`
- Ollama (запущен локально на `http://127.0.0.1:11434`)
- Токен Telegram бота

## 🛠 1. Установка Ollama

Для работы нейросети необходимо установить Ollama на ваш компьютер.

* **Windows**: Скачайте установщик с [официального сайта](https://ollama.com/download) и запустите его.
* **Linux**: Выполните команду в терминале:
  ```bash
  curl -fsSL [https://ollama.com/install.sh](https://ollama.com/install.sh) | sh
  ```
* **macOS**: Скачайте с [официального сайта](https://ollama.com/download) или используйте Homebrew:
  ```bash
  brew install ollama
  ```

После установки запустите Ollama и скачайте нужную модель:
```bash
ollama serve
# В отдельном окне терминала скачайте модель:
ollama pull qwen2.5-coder:0.5b
```

## 🚀 2. Установка проекта (через `uv`)

Мы используем `uv` — современный менеджер пакетов.

### Установка `uv`
* **Windows** (в PowerShell): `powershell -ExecutionPolicy ByRef -c "irm https://astral.sh/uv/install.ps1 | iex"`
* **Linux / macOS**: `curl -LsSf https://astral.sh/uv/install.sh | sh`

### Настройка бота
1. Клонируйте репозиторий:
```bash
git clone https://github.com/vheris/programmBot
cd programmBot
```

2. Установите зависимости (виртуальное окружение создастся автоматически):
```bash
uv sync
```

3. Запустите бота:
```bash
uv run bot.py
```

## Использование

1. Откройте Telegram и найдите бота.
2. Отправьте команду `/start`.
3. Выберите **исходный язык** (из какого переводить).
4. Выберите **целевой язык** (на какой переводить).
5. Отправьте код:
   - Текстом прямо в чате
   - Файлом (поддерживаются все текстовые форматы)
6. Получите конвертированный код.
7. Выберите "Хочешь конвертировать ещё?" для новой конвертации.

## Безопасность

**Внимание**: Токен бота находится в коде в открытом виде. Для production-использования:

- Переместите токен в переменную окружения (`.env`)
- Используйте `python-dotenv` для загрузки из `.env`

Пример:
```python
from dotenv import load_dotenv
import os

load_dotenv()
bot = AsyncTeleBot(os.getenv('TELEGRAM_BOT_TOKEN'))
```

Основные параметры можно изменить в файлах:

```python
OLLAMA_BASE_URL = "[http://127.0.0.1:11434](http://127.0.0.1:11434)"  # URL сервера Ollama
OLLAMA_MODEL = "qwen2.5-coder:0.5b"         # Модель для конвертации
```

## Решение проблем

### Бот не отвечает
- Проверьте, что токен в `bot.py` актуальный.
- Убедитесь, что интернет-соединение есть.

### Ошибка "Connection refused"
- Убедитесь, что Ollama запущен: `ollama serve`.
- Проверьте URL: `curl http://127.0.0.1:11434`.

### Модель не найдена
- Скачайте модель вручную: `ollama pull qwen2.5-coder:0.5b`.

### Таймаут при конвертации
- Увеличьте timeout в `ollama_async.py` (сейчас 120 секунд).
- Проверьте мощность ПК — модель требует ресурсов.

## Документация API

Документация собирается автоматически из docstrings функций. Для генерации файла `API.md` выполните команду:

```bash
uv run gen-docs
```

Файл `API.md` появится в корне проекта.

## API

### `ollama_chat(messages: list, model: str) -> str`

Отправляет запрос к Ollama и возвращает ответ модели.

**Параметры:**
- `messages` — список словарей `{"role": "user/system", "content": "..."}`
- `model` — имя модели (по умолчанию `qwen2.5-coder:0.5b`)

**Возвращает:**
- Строку с ответом модели
